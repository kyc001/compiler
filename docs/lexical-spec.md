# 当前词法规格

以《SysY2022语言定义-V1》和《SysY文法补充说明》为依据。
当前阶段只识别 Token，数值类型转换、取值范围检查和类型检查属于后续语义分析。

| 记号 | 正则定义或集合 |
| --- | --- |
| 标识符 | `[A-Za-z_][A-Za-z_0-9]*` |
| 关键字 | `const int float void if else while break continue return` |
| 十进制整数 | `[1-9][0-9]*` |
| 八进制整数 | `0[0-7]*` |
| 十六进制整数 | `0[xX][0-9a-fA-F]+` |
| 十进制浮点数 | `([0-9]+\.[0-9]*|\.[0-9]+)([eE][+-]?[0-9]+)?` 或 `[0-9]+[eE][+-]?[0-9]+` |
| 十六进制浮点数 | `0[xX]([0-9a-fA-F]+\.[0-9a-fA-F]*|\.[0-9a-fA-F]+|[0-9a-fA-F]+)[pP][+-]?[0-9]+` |
| 双字符运算符 | `<= >= == != && ||` |
| 单字符运算符 | `+ - * / % = < > !` |
| 界符 | `( ) { } [ ] , ;` |

采用最长匹配，识别标识符之后再判断是否为关键字。注释和空白不生成 Token。
`//` 注释到换行前结束，`/* */` 注释到第一次出现的结束标记结束，不嵌套。
按照当前 SysY 数值文法，暂不支持 C 的整数和浮点字面量后缀。

保留数值的原始文本，避免将 `2147483648` 过早截断为 32 位整数。
`-2147483648` 产生负号和整数字面量两个 Token；`++a` 产生两个加号与一个标识符。
浮点字面量后续应依照补充说明先以 double 解析再转换为 float。

命令输出为 TSV，三列分别是从 1 开始的 `行:列`、Token 类别、原始文本，最后输出 EOF。
数字格式错误、未闭合注释和非法字符均返回非零状态并给出位置。
